# 评测、试点与停止条件

以下为验证计划，没有实测数据和提升百分比。20条验收样例只是规则种子，不能据此推断生产性能。

## 1. 成功不是“回答数量更多”

主指标：**证据合格答复率**。分母为可回答任务中已发起的全部请求（含超时/错误），分子为回答正确、版本适用、关键参数有有效引用且经审核可用的请求。不可答任务单独看正确拒答率，防止靠全拒答提高正确率。

| 指标 | 定义 | 设计目标/限制 |
| --- | --- | --- |
| 证据合格答复率 | 上述分子/分母 | 初步门槛≥90%，须审核确认 |
| 无依据参数率 | 有未经资料支持参数的答复/已生成答复 | ≤2%，设计目标不是结果 |
| 正确拒答率 | 正确拒答的不可答请求/不可答请求 | ≥95%，同时检查过度拒答 |
| 越权泄漏 | 暴露受限标题、片段、参数的用例数 | 0，发现任一例停止试点 |
| 人工答复完成时长 | 从收到任务到形成审核合格草稿 | 与搜索基线配对比较中位数/P90 |
| 响应时长 | 客户端提交至完整状态返回 | 目标P95≤8秒；超过15秒超时 |
| 成本/合格答复 | 模型+检索+基础设施+审核成本 / 合格答复数 | 必须计入被拒答、重试与审核 |

目标值按场景风险初拟，当前没有模型配置、负载和成本实测，不能宣称达标。

## 2. 离线集设计

在获得数据许可后，计划构建至少100个脱敏问题：60可答、15缺字段、10无依据、10版本冲突、5风险接管；另建独立权限/注入回归集。这是计划数，尚未收集。

每条标注问题、身份范围、型号/版本、预期状态、参考片段、必须项、禁止项、人工说明。两位专业人员独立审核并仲裁分歧，保留一致率；开放式答案不靠关键词检查判定通过。

开发集与盲测集分开，同类问题不跨集合泄漏；记录文档、索引、prompt和模型版本。修复错误后先回归失败类，再完整盲测。小样本零泄漏不证明永远安全。

## 3. 故障归因

错型号/缺来源 → 检查元数据与过滤；召回不到 → 检查解析、切分与索引；召回正确但答错 → 检查prompt/生成/参数验证；来源打不开 → 检查引用服务与权限；超时 → 拆分解析、检索、模型时间。不能把所有错误都归因于模型。

## 4. 试点与对照

先离线安全测试，再影子运行（输出不进入正式答复），最后小组人工审核试点。对照为现有关键词搜索+人工整理，任务难度和资料版本保持一致，交叉顺序平衡学习效应；记录审核后的时长与错误，不只记录点赞。

若用户数足够，可按用户随机分组并固定分配，避免同一人两个组来回切换造成污染。A/B前先根据基线、预期效应、功效和分组内相关性算样本量；没有这些输入就不杜撰MDE和显著性。先查分流比例异常，再看效果和护栏。小试点使用描述性结果，不声称统计显著。

## 5. 放量和回退

试点门槛：全部P0安全与状态用例通过；离线指标经领域审核人签字；实际负载验证时延；数据负责人批准留存与模型边界。

任意越权泄漏、危险操作指令、错误对外承诺立即暂停生成。关键参数错误连续出现或护栏超标，关闭生成保留授权搜索，通知负责人并加入回归集。回退必须连同模型、索引、prompt及资料版本回到已审核快照。
